# Frame: the problem and its names

This file states the problem of questions written into study material, in one sentence. It then defines the terms every file of this folder uses, gives the names that research and practice use, and lists the sub-questions.

## The problem in one sentence

Decide how the questions inside a study text are written, placed and answered, so that answering them makes a learner who studies alone learn more than reading the same text.

## Terms used in every file of this folder

| Term | Definition |
|---|---|
| **practice question** | a question written into study material for the learner to answer, not to grade them |
| **item** | one question with its expected answer; the word of the testing literature |
| **stem**, **options**, **key**, **distractor** | the question part of a multiple-choice item, its answer choices, the correct choice, and a wrong choice |
| **lure** | a distractor seen as a source of false learning, in the memory literature |
| **item-writing flaw** | a breach of an item-writing guideline, such as "all of the above" or a clue to the key |
| **free recall**, **cued recall**, **short answer** | write all one remembers; produce one answer to a cue; produce a short constructed answer |
| **recognition** | choose the answer among given ones; multiple choice is the common case |
| **covert** and **overt retrieval** | answering in one's head; answering by writing, typing or speaking |
| **question level** | the kind of thinking a question asks, usually named by Bloom's taxonomy: remember, understand, apply, analyse, evaluate, create |
| **transfer** | answering a new question that the practice question did not ask (core [frame](https://github.com/Tewf/reader-ergonomics/blob/c08433c4d868d9b38ac1441f58ae7602c399db6d/evidence/learning-science/frame.md)) |
| **KR**, **KCR**, **EF** | feedback types: knowledge of result (right or wrong), knowledge of correct response (the answer), elaborated feedback (an explanation) |
| **AUC** | answer-until-correct: the learner keeps choosing until the key is found |
| **immediate** and **delayed feedback** | feedback right after each answer; feedback after a set of answers or a time gap |
| **presearch availability** | the answer is visible, or reachable, before the learner has answered (Kulhavy 1977): peeking |
| **AQG** | automatic question generation; **AIG**, automatic item generation, its testing-industry form |

## What the field calls it

| Our words | The field's names | Entry point |
|---|---|---|
| questions in a study text | **adjunct questions**, inserted questions, post-questions | Hamaker 1986 (core); Andre 1979 |
| answering them to learn | **test-enhanced learning**, testing effect, retrieval practice, practice testing, quizzing | Yang 2021 (core); Pan 2018 |
| the kind of question | question level, higher-order questions, Bloom's taxonomy, transfer-appropriate processing | Agarwal 2019; Jensen 2014 |
| the format | test format, recall against recognition, constructed against selected response | Rowland 2014 (core); Smith 2013c |
| writing a good item | **item writing**, item-writing guidelines and rules, item-writing flaws | Haladyna 2002; Downing 2005 |
| the wrong answers | distractors, lures, functional distractors, misconception-based distractors | Gierl 2017; Sadler 1998 |
| the answer shown after | **feedback**, formative feedback, corrective feedback, elaborated feedback | Hattie 2007; Shute 2008 |
| when it is shown | feedback timing, delay-retention effect | Kulik 1988; Kandemir 2026 |
| where the answer sits | presearch availability, peeking, answer availability | Kulhavy 1977; Anderson 1971 |
| questions written by a program | AQG, AIG, distractor generation, LLM question generation | Kurdi 2020; Alhazmi 2024 |

## What practitioners call it

| Practitioners say | The field says |
|---|---|
| review questions, end-of-chapter questions, check your understanding, self-test | adjunct post-questions |
| quiz, low-stakes quiz, formative quiz, knowledge check | practice testing in a class |
| challenge (with a folded solution) | adjunct question with presearch availability controlled by a fold (Carpentries 2026p) |
| MCQ, single best answer, test bank | multiple-choice items |
| "plausible wrong answers" | functional distractors |
| answer key, answers to odd-numbered exercises, solutions manual | feedback placed away from the question |
| deferred feedback, immediate feedback, interactive with multiple tries | delayed feedback, immediate feedback, AUC (Moodle 2025) |
| AI-generated quiz | AQG with a large language model |
