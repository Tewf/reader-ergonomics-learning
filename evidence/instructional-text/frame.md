# Frame: the problem and its names

Step 1 for the explanatory study text: the problem in one sentence, its terms, what research and practice call it, the sub-questions, and the works linked rather than reviewed.

## The problem in one sentence

Decide which parts to build around the explanation of a study text (objectives, key terms, summaries, boxes, notes and guides), so that a learner who studies it alone learns what it states as its aims.

## Terms used in every file of this folder

| Term | Definition |
|---|---|
| **instructional text** | prose written to be studied, such as a textbook section, a lesson, a lecture handout or course notes |
| **apparatus** | the parts placed around the explanation; textbook research calls each one a **pedagogical aid** |
| **learning objective** | a statement of what the learner will be able to do after the text; older work says **behavioural objective** |
| **alignment** | objectives, teaching and assessment that ask for the same performance |
| **backward design** | writing the objectives first, then the assessments, then the content |
| **key term** | a word the text marks as one to learn, usually in bold, with its definition |
| **glossary** | a list of key terms with definitions, at the end of a chapter or book or running in the margin |
| **gloss** | a short definition placed beside a word, in the margin or by a link |
| **summary** | a short restatement of the main points, placed before or after a part |
| **misconception** | a wrong idea a learner brings to the text, often resistant to change |
| **refutation text** | a text that states a misconception, says it is wrong, and gives the accepted explanation |
| **guided notes** | instructor handouts with the structure of a lesson and blanks the learner fills in |
| **study guide** | a document given to learners to direct their study for a test: topics, terms, questions |
| **crib sheet** | a sheet or card of notes a learner prepares and may consult during an exam |
| **instructional explanation** | an explanation given by the material, as against one the learner produces |
| **worked solution** | a solved problem with its steps shown, printed as a key or a solutions book |
| **boxed text** | text set apart from the main column in a frame, as a side feature |

## What practitioners call it

| Practitioners say | The field says |
|---|---|
| learning objectives, "by the end of this section you will be able to" | instructional objectives (OpenStax 2026b; CMU 2025) |
| questions, objectives, key points of an episode | objectives and summary, required by a lesson template (Carpentries 2026a) |
| lesson design process, outcomes first | backward design (Carpentries 2026b; Wilson 2019) |
| course design rubric, alignment standards | instructional alignment, audited by peer review (Quality Matters 2026b) |
| key terms in bold, glossary | typographical cueing and glosses |
| section summary, key takeaways, key points | adjunct summaries |
| common misconceptions box | refutation text |
| fill-in notes, skeleton notes | guided notes |
| revision guide (United Kingdom), study guide (United States) | study guide; no research term for the revision guide was found |
| cheat sheet, formula sheet, crib card | crib sheet |
| solutions manual, worked solutions, answer key | worked solutions; their access is the exercise-sets review's question |
